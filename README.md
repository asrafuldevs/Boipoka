# Boipoka

Boipoka is a React-based book listing web application where users can browse books, open detailed book information, and save books to **Read List** or **Wishlist** using local storage.

## Live Link

[Visit Boipoka](https://asrafuldevs.github.io/Boipoka/)

## Features

- Browse all books from a JSON data source
- View full details for each book
- Add books to Read List and Wishlist
- Responsive UI built with Tailwind CSS + DaisyUI
- Client-side routing with React Router

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- DaisyUI
- React Toastify

## Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/asrafuldevs/Boipoka.git
   ```
2. Go to the project directory:
   ```bash
   cd Boipoka
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
